# 实施示例使用说明

1. 先在数据集管理中登记“工程进度示例.json”为启用的静态 JSON 数据集。
2. 示例数据集编码使用 manual-progress-20260906；若自行更改编码，导入前同步修改页面配置中的 datasetCode。
3. “工程进度页面配置.json”是完整页面配置，可在新建页面的设计器中导入；再检查、保存、预览和发布。
4. 其他 JSON 文件对应下表组件，用于新建练习数据集；不是页面配置，不要在页面 JSON 导入中直接使用。
5. 示例值不代表现场业务；资源、地图、视频、接口和权限请按项目文档配置。环形文字当前排布限制请以当前组件说明和界面限制为准。
