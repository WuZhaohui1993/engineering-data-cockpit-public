# 大屏组件测试数据

这组虚构样本用于验证组件取数、字段映射、过滤、空态和平台实时通道，不代表任何现场业务数据。定义见 [dashboard_component_test_data.sql](../ruoyi-backend/sql/dashboard_component_test_data.sql)，共 11 个固定编码数据集，分组为 `component-test`。

## 加载与清理

按[本地测试指南](本地测试指南.md)准备专用测试库和 `config/ruoyi-local.env` 后，在项目根目录执行：

```bash
./scripts/load-dashboard-component-test-data.sh
```

脚本新增或覆盖这 11 个数据集及测试分组，并检查数量、JSON 合法性和启用状态；重复加载会覆盖对这些样本的手工修改。清理命令如下，执行前先解除测试页面对样本的引用：

```bash
./scripts/load-dashboard-component-test-data.sh remove
```

清理直接删除固定编码的数据集，仅在分组为空时删除分组，不会替测试页面修复绑定。

## 绑定速查

下表箭头表示“组件字段角色 → 数据集字段”：

| 数据集 | 用途 | 绑定或配置 |
| --- | --- | --- |
| `test-component-kpi` | 指标、翻牌、统计概览、仪表、进度、颜色块 | 指标 `value → value`；统计概览使用 `label/value/suffix/compareValue/compareLabel/compareState`；颜色块 `value → color`，文字在样式中配置 |
| `test-component-series` | 分类、多系列、散点、文字云及轨道环形文字 | `category → category`、`value → actualValue`；多系列选 `actualValue/planValue/lastYearValue`；散点 X 轴映射 `sequence`；环形文字可用 `category` |
| `test-component-calendar` | 日历热力图 | `category → date`、`value → value`；样本固定为 2026 年 8 月，日历范围须包含该月 |
| `test-component-table` | 表格、轮播、卡片、排名 | 按需选择展示字段；排名建议明确指定名称和数值字段，使用 `score` 验证排序 |
| `test-component-alerts` | 告警与长文本 | 选择 `level/title/location/status/eventTime/description` |
| `test-component-realtime` | 实时列表 | `dataType=WEBSOCKET`、`mode=POLL_BRIDGE`、`sourceType=JSON`；平台每 5 秒轮询内置 JSON，不连接外部系统 |
| `test-component-map-points` | 区域、点位、柱形、热力及排名地图 | `label/value/longitude/latitude` 映射同名字段；地图选择 `/dashboard/assets/map/demo-region.json` |
| `test-component-map-flows` | 飞线与时间轴飞线 | 起终点名称、经纬度和 `value` 映射同名字段；时间轴另设 `group → group`；使用同一内置地图 |
| `test-component-weather` | 天气 | 样式中指定 `city/temperature/condition` 对应同名字段；仅为静态天气样本 |
| `test-component-filtered` | 查询表单参数联动 | SQL 只读查询平台 `dashboard_dataset`；声明必填参数 `keyword`，默认“组件” |
| `test-component-empty` | 数据组件空态 | 返回 `NO_DATA`，显示空态，不把空数据当作数值 0 |

除了 `test-component-filtered`，样本均未声明请求参数。过滤样本按数据集名称查询整张平台元数据表，因此行数随测试库内容变化；分别输入“指标”“组件”和不存在的关键词，验证返回内容变化及无数据场景，不固定断言 1 行。

## 验证顺序与资源边界

1. 在数据集管理中逐项“测试”，核对有数据样本的 `SUCCESS` 和空样本的 `NO_DATA`。
2. 在测试页绑定指标、图表和表格，保存重开、预览并检查数值格式、字段和排序；查询表单绑定已声明的 `keyword` 参数。
3. 核对地图区域名称、坐标和飞线分组；实时列表确认实际收到平台 WebSocket 消息。
4. 在测试页验证空态、发布和只读分享。轮询桥接通过不能证明上游原生 WebSocket、心跳重连或现场实时性通过。

时间、文本、富文本、图标、按钮、边框、装饰线、表单和选项卡可直接配置；图片、视频先在资源管理登记。内嵌页面仅允许平台运行路径 `/dashboard/runtime/<页面编号>` 或 `/dashboard/runtime/code/<页面编码>`，保留登录权限校验，并禁止自身或嵌套递归；自定义内容使用隔离沙箱。

这 11 个样本不覆盖所有业务字段模型。甘特日期/依赖、具体媒体文件、复杂表单和其他交互按[用户说明书示例](examples/README.md)补充，不能以样本加载成功代替组件验收。
