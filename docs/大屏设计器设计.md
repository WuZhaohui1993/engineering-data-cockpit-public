# 大屏设计器设计

本文按当前工作区实现维护，说明配置结构和功能边界。操作步骤见[使用说明](examples/README.md)，验证结果见[测试与已知限制](测试与已知限制.md)。

## 工作区与编辑

设计器运行在管理端布局中：左侧为组件库和图层，中间为像素坐标画布，右侧为页面属性或组件的基础、数据、样式、交互属性，顶部提供保存、预览、发布和编辑工具。

页面管理打开的页签显示“页面名称 · 设计/运行/预览”，按路由路径分别维护。运行画布内部切页复用入口页签并保留入口名称；部署菜单继续使用菜单名称，不删除其他已打开的设计或运行页签。

已提供选择、多选、拖动、缩放、旋转、8 像素网格吸附、对齐与分布、组合/取消组合、显隐与锁定、图层排序、复制/粘贴/剪切/删除、撤销/重做、组件预览、页面 JSON 导入导出和页面复制。组合通过 `groupId` 关联组件，不生成另一套嵌套画布；有历史问题但尚未定向复测的编辑操作见测试文档。

属性按组件能力及开关状态显示，隐藏入口保留已保存配置。管理外壳和属性控件跟随 RuoYi 的明暗主题、主题色和全局尺寸；画布业务主题由页面配置控制。标题装饰使用资源管理中的标题栏切图，小数位和数量级位于“数据 → 数值格式”。

## 当前组件

设计器与后端白名单均为 **53 类**。组件编码、字段映射和逐项属性由[自动覆盖矩阵](../output/component-property-audit/组件属性逐项覆盖矩阵.md)维护，避免在多份文档重复列属性。

| 分类 | 数量 | 组件 |
| --- | ---: | --- |
| 数据组件 | 13 | 指标卡片、数字翻牌、统计概览、数据表格、高级表格、图文记录列表、轮播表格、卡片轮播、计划甘特图、里程碑时间轴、排名表、告警列表、实时列表 |
| 图表组件 | 16 | 折线图、柱状图、通用图表、饼图、环形图、仪表盘、进度图、漏斗图、雷达图、散点图、面积图、象形图、矩形树图、日历热力图、文字云、3D 柱形图 |
| 可视化组件 | 10 | 受控地图、飞线地图、柱形地图、热力地图、柱形排名地图、时间轴飞线、天气预报、当前时间、轨道环形文字、颜色块 |
| 基础组件 | 14 | 查询表单、设计器表单、在线表单（查询）、选项卡、文本、富文本、图标、按钮、图片、视频、内嵌页面、自定义内容、边框、装饰线 |

通用图表支持 10 种受控子类型；3D 柱形图是等距立体效果。富文本按纯文本展示，三个表单组件只提交查询参数，不写回业务系统。甘特图支持基准/实际日期、依赖关系、当前日期标线以及进度/状态提示；实际效果取决于字段映射与输入数据。

普通数据表格开启自动滚动后，表头固定，正文以跑马灯方式连续向上循环。滚动速度沿用 `style.tableScrollSeconds`（1–60 秒/行，越小越快），内容是否滚动由实际可视高度决定，不再按固定 6 行轮换；数据仍受 `binding.rowLimit` 限制。鼠标悬停或表头控件获得焦点时暂停，移开或失焦后继续。设计画布、独立组件预览、运行及分享使用同一实现。

## 页面配置

页面以 JSON 保存，当前导出版本标识为 `schemaVersion: "1.0"`。以下是主要字段；以设计器导出内容和服务端校验为准，不手工套用其他页面的数据集或资源编码。

| 字段 | 含义与当前约束 |
| --- | --- |
| `canvas.width/height` | 默认 1920×1080；设计器控件范围为宽 640–7680、高 360–4320，后端允许宽 320–10000、高 240–10000 |
| `canvas.scaleMode` | 常规运行：`contain` 等比适应，或 `stretch` 拉伸铺满 |
| `canvas.fullscreenScaleMode` | 全屏：`contain`、`cover` 自适应铺满并可滚动查看超出内容，组件保持比例，或 `stretch` |
| `canvas.hideScrollbar` | 运行/分享画布是否隐藏滚动条；隐藏后仍可通过滚轮、触控板和键盘滚动 |
| `canvas.theme/palette/paletteColors` | 深浅主题、五套预置配色及颜色数组；组件可选择跟随配色或单独设置 |
| `canvas.background/watermark` | 平台背景图片、显示方式、位置和水印 |
| `refresh` | 页面默认数据刷新：`interval` 为 5–3600 秒，`daily` 使用运行端时区 `HH:mm`；仅调度跟随页面的组件，关闭不影响独立周期与实时推送 |
| `filters` | 页面查询参数声明：`id`、`label`、`parameter`、`type`、`defaultValue`、`targetWidgetIds` |
| `widgets` | 最多 200 个组件，每个 `id` 在页面内唯一 |
| `widgets[].layout/state/groupId` | 位置、尺寸、层级、旋转、显隐、锁定及组合标识；组件布局不得超出画布 |
| `widgets[].binding` | 数据来源、数据集、字段映射、静态行、参数、过滤、展示字段、条数和刷新间隔 |
| `widgets[].style/interaction` | 受控样式和点击动作；服务端检查配置、资源、字段及动作是否合法 |

单页配置最多 512×1024 个字符。保存、预览和发布依赖服务端校验，前端控件可见不代表任何输入都能保存或执行。

保存时仅压缩不属于当前组件的默认标量样式，并清除可重建的编辑器文本。查询表单字段、选项、选项卡、静态数据、字段映射及当前组件的样式完整保留，不能按默认数组或数组下标删除业务配置。

## 数据、过滤与交互

- 数据来源支持数据集和静态 JSON 行，两者不能同时使用。数据集类型为 `SQL`、`API`、`JSON`、`WEBSOCKET`；组件不直接连接数据库或外部数据端点。
- 页面属性保留“数据自动刷新”作为默认周期，组件数据刷新间隔为 0 时跟随；独立周期可设置 5–3600 秒，历史 1–4 秒配置仍按最短 5 秒执行，编辑时归一到 5 秒。预览不启动定时轮询，但实时连接仍可接收推送。
- 字段映射和参数必须对应数据集声明。多系列最多 12 个数值字段，展示条数为 1–1000；组件刷新为 0–3600 秒，其中 0 跟随页面。
- 页面过滤器类型为 `STRING`、`NUMBER`、`DATE`、`DATETIME`。`targetWidgetIds` 为空时作用于使用同名参数的组件，否则仅作用于指定组件；表单字段通过 `parameter` 或 `filterId` 引用声明。
- 选项卡的 `style.tabs` 保存标题、纯文本和 `widgetIds`，控制已有组件的显示范围。查询表单与图表联动要使用能消费参数的数据集；静态 JSON 样本不会因提交任意关键词自动变化。
- 点击动作包括联动过滤、详情弹框、打开平台页面、页面钻取、组件逐级钻取和浏览器链接。站内目标受权限与发布状态约束；浏览器链接仅接受校验后的 HTTP/HTTPS 地址并在新标签打开。
- 登录运行态可按 `/dashboard/runtime/code/{pageCode}` 访问当前发布版本；分享内页面跳转只能访问分享集合允许的页面和固定版本。

## 图表、资源与自定义内容

图表和地图使用受控配置构造器。图例、坐标轴、标签、配色、提示框等仅对适用组件开放；不接受带函数的 ECharts 配置或任意查询脚本。地图使用平台 GeoJSON，坐标和区域字段由数据集提供。

背景图、图片、标题切图、视频和封面引用平台资源。页面 JSON 保存 `/profile/...` 或 `/dashboard/assets/...`，浏览器使用统一 `dashboardResourceUrl()` 适配环境前缀。视频支持静音自动播放、循环和控制条，是否实际播放仍受浏览器策略及编码支持影响。

内嵌页面在当前前端仅接受其他大屏运行页（数字 ID 或页面编码），保留目标页登录和权限检查，阻止外部地址、管理页、直接循环和继续嵌套。

自定义内容在无同源权限的 `sandbox="allow-scripts"` iframe 中运行受控内联 HTML/CSS/JavaScript；后端限制外部脚本、网络地址、事件属性、嵌套框架和凭证访问，数据与跨组件操作经 JLink 消息协议处理。此能力不能用作任意脚本或外部网页入口。

## 草稿、预览、发布与分享

| 状态 | 读取内容 | 边界 |
| --- | --- | --- |
| 设计态 | 草稿、配置预览及受控数据 | 保存不改变已发布版本 |
| 预览态 | 优先当前草稿，无草稿时回退发布版本 | 受登录权限保护；回退发布版本时只读 |
| 运行态 | 当前已发布版本 | 支持刷新、联动和导航，停用或未发布页面不能正常运行 |
| 分享态 | 令牌绑定的发布版本集合 | 匿名只读；服务端校验有效期、撤销、页面、版本、组件和数据集范围 |

运行态分别呈现 `SUCCESS`、`NO_DATA`、`NOT_CONNECTED`、`SOURCE_ERROR`、`TIMEOUT` 等质量状态；无数据不作为数值 0 或真实来源成功处理。
