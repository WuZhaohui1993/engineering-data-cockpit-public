# 安全与许可证

本文区分当前代码控制与尚未提供的保护，不作为生产安全验收报告。验证范围见[测试与已知限制](测试与已知限制.md)。

## 当前控制

| 边界 | 实现 |
| --- | --- |
| 管理权限 | Controller 使用 RuoYi `@PreAuthorize`；菜单/按钮权限见[权限与接口设计](权限与接口设计.md) |
| 运行取数 | 服务端读取页面版本，校验组件与数据集绑定；正式运行只执行启用数据集 |
| 分享 | 哈希验证令牌、期限和撤销状态，逐次核对成员页面、固定版本和绑定 |
| SQL | 只读连接、预编译绑定、SELECT/WITH 检查、禁止多语句/注释及写操作关键词，超时和最多 1000 行 |
| 新 HTTP endpoint | 默认要求 HTTPS；校验主机、端口、CIDR、解析地址、IPv4-mapped IPv6、回环/私网/云元数据并禁止重定向，按声明参数编码并由服务端注入凭证 |
| 入站 Open API | 独立于后台 JWT，按接入方校验 API Key/Bearer/HMAC、时间窗、nonce、原始正文摘要、IP/Origin、速率、并发、schema、范围和幂等 |
| 页面 | 组件、字段映射、布局、资源、交互及图表配置校验；站内跳转和浏览器链接分别校验，拒绝不允许的脚本配置 |
| 第三方媒体 | 浏览器只使用不透明引用；服务端校验页面/版本/分享、同记录参数、字节、魔数、尺寸/像素/帧和完整解码，使用安全响应头并清理 PNG/JPEG 元数据 |
| 资源/地图 | 平台路径白名单；GeoJSON 通过受控资源接口读取；内部 iframe 仅接受平台大屏路径 |
| 自定义 HTML | 服务端检查危险能力；运行在 `sandbox="allow-scripts"` iframe，CSP 禁止网络连接、外部框架和表单提交；允许受限内联脚本 |

普通组件与沙箱 HTML 的能力不同，不能笼统声称“没有 HTML/脚本执行”。具体字段限制见[大屏设计器设计](大屏设计器设计.md)。

## 密钥与环境配置

| 配置 | 用途 |
| --- | --- |
| `DASHBOARD_DATASOURCE_ENCRYPTION_KEY` | AES-GCM 加密数据源凭证；空值时不能保存非空凭证，应稳定注入并独立备份 |
| `dashboard.datasource.allowed-hosts` | 管理端登记 MySQL 来源的主机白名单，代码默认 `127.0.0.1,localhost` |
| `DASHBOARD_API_ALLOWED_HOSTS` | HTTP 来源主机白名单 |
| `DASHBOARD_INTEGRATION_ALLOW_LOCAL_DEVELOPMENT_TARGETS` | 仅供隔离本地测试显式允许回环/局域网目标；生产保持 `false` |
| `DASHBOARD_INTEGRATION_ALLOW_PLAIN_HTTP` | 保留专网明文/隔离测试开关；正式公网 HTTP 使用来源级 `PUBLIC_HTTP` 和主机、端口白名单，不依赖此开关，当前生产保持 `false` |
| `DASHBOARD_INTEGRATION_RECOVERY_INTERVAL_SECONDS` | 入站未完成批次和过期数据维护周期 |
| `DASHBOARD_WEBSOCKET_ALLOWED_HOSTS` | 上游 WebSocket 主机白名单 |
| `DASHBOARD_WEBSOCKET_ALLOWED_ORIGIN` | 浏览器 WebSocket Origin 白名单；启动拒绝空列表或单独的 `*` |

凭证只通过被忽略的本地环境文件或部署环境注入，不写入文档、源码和命令输出。普通来源摘要不回传密文、账号或基础地址。配置编辑使用独立权限和禁止缓存的专用接口；该操作的日志不保存请求/响应正文，凭证由部署环境安全注入并保留原密文。密钥变化不会自动迁移历史密文。

## 已知边界

- 大屏业务查询没有页面 ACL、项目/部门行级隔离。筛选参数与前端隐藏按钮不能替代授权。
- 新 `sourceCode + endpointCode` API 会按字段声明裁剪、转换和脱敏；旧 API、SQL、JSON 和 WebSocket 仍主要把 `fieldSchemaJson.show/mask` 当作展示配置。对外分享前仍须在来源查询层限定数据范围。
- 新 HTTP endpoint 每次请求前解析并校验地址，但本轮没有在真实代理和 DNS 基础设施中验证 DNS 重绑定、代理绕过或出口策略；旧 API/WebSocket 与 `master` 兼容路径仍需独立最小权限和网络限制。
- 新 HTTP endpoint 有字节/JSON 深度和字段配额、有限重试、并发舱及内存断路；没有通用分页、持久快照、分布式限流或跨实例断路状态。
- 分享明文 `share_token` 用于管理端再次复制，地址是访问凭证；无密码保护或访问次数限制。反代访问日志也应避免保存完整分享路径及 WebSocket 查询令牌。
- 控制器写操作使用 RuoYi 操作日志，入站接收台账记录批次和处理结果；没有覆盖每次运行、匿名访问和媒体下载成功失败的独立审计流水。异常消息也不能宣称已完成所有字段和网络信息的脱敏。
- 入站使用数据库租约及事务行锁；双实例并发、实例中断恢复、真实 SQL 故障死信与重放已本地验证；断路和死信产生站内告警，现场容量及外部通知渠道另行验收。
- 公网部署还需配置 HTTPS、SPA history fallback、API/WebSocket 反代、正式 Origin 和数据源白名单。当前文档整理未执行渗透测试、依赖漏洞扫描或生产恢复演练。

第三方入站接口已使用 `/open-api/v1/integrations/**` 独立边界，不能沿用页面 WebSocket 或匿名分享授权。开放公网前仍须按[第三方数据接入需求](第三方数据接入需求.md)完成真实调用方、TLS/WAF、可信代理来源 IP、签名测试向量、容量、告警、多实例租约和恢复验收。

## 许可证

保留 [后端 MIT 许可证](../ruoyi-backend/LICENSE)和[前端 MIT 许可证](../ruoyi-ui/LICENSE)中的 RuoYi 版权及许可文本。界面品牌调整不改变上游许可义务。

当前使用 Vue、Vite、Element Plus 和 ECharts，具体版本以构建文件与锁文件为准；ECharts 按 Apache-2.0 要求处理随附声明。JimuReport/JimuBI 未引入为 Maven/npm 依赖，其早期调研不构成本项目功能或许可证承诺。

新增依赖和对外发布时按实际分发包核对许可、版权及 NOTICE；仓库当前没有完整 SBOM/第三方许可证清单或扫描报告，不能写作已完成供应链验收。
