# 数据集与数据源设计

以 `DashboardService`、`DashboardMapper.xml` 和 `src/api/dashboard.js` 为准。数据集由服务端执行，运行页面只提交页面、组件、数据集编码及参数/过滤器。管理接口和权限见[权限与接口设计](权限与接口设计.md)。两种外部接入方向的业务需求、入站推送契约和实施分期见[第三方数据接入需求](第三方数据接入需求.md)。

## 数据源

数据源在“数据管理 → 数据源”统一维护，HTTP 接口位于所属来源详情；数据集在同页“数据集”页签中配置，两者通过页签切换。目录和分页操作沿用数据管理页面的统一规则。

数据源、推送接入和数据集使用统一文件夹操作，各自保留独立目录。数据源和接入方以 `folderId` 归档，数据集继续保留 `groupCode`；目录不影响连接、接收范围或页面绑定。目录操作和权限沿用数据管理页面的统一规则。

| 字段 | 当前约定 |
| --- | --- |
| `sourceCode` / `sourceType` | 编码创建后不可修改；类型为 `MYSQL`、`HTTP`、`WEBSOCKET` |
| `configJson` | MySQL：`jdbcUrl`、`username`；HTTP：`baseUrl`、默认 `path/method`、网络 profile、主机/CIDR/端口、认证、时区、超时和并发；WebSocket：`baseUrl`、`path` |
| `secret` | 仅写入时提交，服务端以 AES-GCM 保存到 `secretCiphertext` |
| `status` | `DRAFT`、`ACTIVE`、`DISABLED`；登记来源必须启用才能执行 |

列表返回可展示摘要；详情中的 `configJson` 不含主机、JDBC 地址、账号和密文，HTTP 保留路径/方法，WebSocket 保留路径，并返回 `configMasked`、`hasSecret`。编辑元数据时不提交连接配置即可保留原值；敏感配置编辑使用独立权限和禁止缓存的配置接口；普通详情仍只返回摘要。空凭证保留原密文，未修改的凭证不会重复提交。有数据集引用时禁止删除，必须先解除引用。

内置来源可复用平台库连接，但不能视为天然只读账号；外部来源和只读权限须由部署环境落实。密钥及主机白名单见[安全与许可证](安全与许可证.md)。

HTTP 来源支持三种出站网络策略：`PUBLIC_HTTPS`（默认，强制 HTTPS）、`PUBLIC_HTTP`（公网 HTTP/HTTPS，必须在该来源显式填写主机和端口白名单）、`PRIVATE_LINK`（批准的专网/CIDR）。`PUBLIC_HTTP` 可在正式环境使用，不依赖开发开关；它仍拒绝私网、回环、链路本地、云元数据及保留地址，且不跟随重定向。配置保存和实际取数复用同一目标校验。该新增选项仅属于出站来源，不改变入站接入方策略。

## 数据集元数据

| 字段 | 当前约定 |
| --- | --- |
| `datasetCode`、`datasetName`、`groupCode` | 稳定引用编码、显示名称、树形分组 |
| `dataType` | `SQL`、`API`、`JSON`、`WEBSOCKET` |
| `configJson` | 类型配置；来源引用和 `rowLimit` 均放在这里，不是独立数据库列 |
| `fieldSchemaJson` | 最多 100 个字段；除展示属性外，新 API 投影使用 `sourcePath/type/required/default/enum/scale/mask` |
| `paramSchemaJson` | 参数名称、类型、必填、默认值、枚举/范围和 `path/query/header/json/form` 位置 |
| `timeoutSeconds`、`refreshSeconds` | 默认 10 秒、30 秒；保存范围为 1–3600 秒 |
| `status` | `DRAFT`、`ACTIVE`、`DISABLED`；页面运行要求 `ACTIVE` |
| `lastTestAt`、`lastTestStatus` | 最近测试时间和质量状态 |

测试接口会更新测试状态，并根据前 100 行样本追加新字段，保留已有字段设置；因此测试不是纯只读操作。新数据集不能直接启用，配置、字段或参数变化会清除测试状态，重新启用前必须测试为 `SUCCESS/NO_DATA`。设计器预览可执行草稿数据集，正式页面运行会拒绝未启用的数据集。

参数类型为 `STRING`、`NUMBER/DECIMAL`、`INTEGER`、`ENUM`、`BOOLEAN`、`DATE`、`DATETIME`。执行器使用默认值、校验必填、范围/枚举并转换类型；使用 `sourceCode + endpointCode` 的新 API 数据集会拒绝未声明参数，旧兼容执行器仍保留忽略行为。组件保存时，`binding.parameters` 的未知参数会被拒绝。

过滤器最多 20 条，只接受已声明字段，操作符为 `eq/ne/contains/gt/gte/lt/lte/isnull/notnull`。页面绑定过滤器与请求过滤器叠加，在取回的数据行上执行；这不是来源数据库的数据权限控制，也不会自动向来源下推查询。

## 四类配置

以下均为 `configJson` 示例，编码和字段仅说明格式。

**SQL**：引用 MySQL 来源，使用只读连接和预编译参数；支持 `:name` 与 `${name}`，包括 `LIKE '%${name}%'` 的绑定转换。

```json
{
  "dataSourceCode": "project-readonly",
  "sql": "SELECT category, amount FROM project_summary WHERE project_code = :projectCode",
  "rowLimit": 100
}
```

只允许 `SELECT`/`WITH`，拒绝多语句、注释及列明的写操作/文件操作关键词。SQL 检查不替代数据库最小权限。SQL 文本可供获授权的数据集管理者编辑，不出现在运行结果中。

**API（新 endpoint 执行器）**：数据源保存连接、网络和来源级认证，一个来源可以登记多个 endpoint。endpoint 决定路径、GET/POST、无体/JSON/表单、JSON/二进制响应、认证 provider、业务信封、容量、重试、缓存和断路策略；数据集只保存复合引用、响应投影和媒体字段映射。已声明参数按位置编码，浏览器不能覆盖主机、路径、方法、请求头或认证策略。

```json
{
  "sourceCode": "project-readonly",
  "endpointCode": "project.summary",
  "response": {
    "rowsPath": "data.records",
    "totalPath": "data.total",
    "businessTimePath": "data.updatedAt",
    "requiredPaths": ["data.records"]
  },
  "rowLimit": 100
}
```

新建 API 数据集必须使用 `sourceCode + endpointCode`。旧数据集仍可按历史 `endpointCode`/环境映射执行和编辑，以保留现有页面；正式第三方接入不得使用该兼容路径。

新执行器支持根数组、嵌套数组和对象单行，按字段白名单转换，缺失必需路径返回 `INVALID_DATA`，超出行数返回 `TRUNCATED`。响应按字节上限读取且不跟随重定向；幂等请求可有限重试并在每次重试重新认证。接口可配置 NONE/PAGE/OFFSET/CURSOR 分页；数据库保存加密原始快照，支持跨数据集与跨实例复用及有界故障过期回退。

媒体 endpoint 使用 `mediaProjections` 从同一来源行提取业务键和受控表单参数。普通结果只返回一次性候选引用；登录页面或分享入口经页面、版本、组件和数据集校验后换取最终 `mediaRef`，再通过独立受保护的媒体路径读取。默认只允许 PNG/JPEG，具体安全边界见[第三方数据接入需求](第三方数据接入需求.md#媒体策略)。

**JSON**：`STATIC` 读取配置数据；`URL` 使用 `urlRef` 引用登记的 HTTP 来源，复用 API 执行器。

统一入口为“数据集管理 → JSON 数据集”，原资源管理的 JSON 标签页操作的也是同一批数据集，现已去重。静态 JSON 编辑支持校验并格式化，错误 JSON 或不存在的数据路径不会提交保存。组件自身“静态数据”只保存在该组件的页面配置内，适合不共享的小样例，不属于数据集管理中的共享记录。

```json
{ "mode": "STATIC", "payload": [{ "label": "完成率", "value": 82.5 }], "rowLimit": 100 }
```

**WEBSOCKET**：执行器按 `sourceType` 选择 `SQL/API/JSON/WEBSOCKET`。前三级使用同类型配置轮询桥接；直连上游使用以下配置。

```json
{
  "mode": "DIRECT",
  "sourceType": "WEBSOCKET",
  "endpointCode": "project.stream",
  "subscribe": { "channel": "events", "enabled": true },
  "message": { "rowsPath": "data.events", "eventTimePath": "data.eventTime" }
}
```

`mode` 不是执行分支的判定字段；轮询桥接应明确填写 `sourceType: SQL/API/JSON`，不要填写 `sourceType: POLL_BRIDGE`。上游模式建立受控连接、按声明发送订阅、读取一条完整 JSON 文本后关闭；建连和读消息各至多 30 秒，没有长连接复用、持续心跳或自动重连执行器。

浏览器连接 `/dashboard/runtime/ws` 或分享入口 `/dashboard/runtime/share/ws`。每连接固定一个组件/数据集，按 `refreshSeconds` 推送；最多 100 个平台连接，客户端消息限 4096 字节，相邻消息至少间隔 250 毫秒，只接受 `subscribe`、`refresh`。握手参数及权限见[权限与接口设计](权限与接口设计.md)。

## 结果契约与限制

```json
{
  "datasetCode": "project-summary",
  "rows": [],
  "quality": "NO_DATA",
  "stale": false,
  "fetchedAt": "2026-09-06T00:00:00Z",
  "requestId": "example-request-id"
}
```

页面绑定执行完成后补充 `pageId/widgetId/revisionId`；部分提前返回的错误结果不含这些字段。API 可增加 `total/businessTime/businessDate/sourceStatus`；上游 WebSocket 可增加 `eventTime`，不保证所有结果都有业务时间、`receivedAt` 或 `sequence`。

质量值包括 `SUCCESS`、`NO_DATA`、`PARTIAL`、`TRUNCATED`、`NOT_CONNECTED`、`INVALID_CONFIG`、`INVALID_DATA`、`TIMEOUT`、`AUTH_ERROR`、`RATE_LIMITED`、`SOURCE_ERROR`、`CIRCUIT_OPEN`、`DATASET_NOT_FOUND`、`DISABLED`、`FORBIDDEN`。无数据、未接入和错误应展示对应状态，不能作为业务数字 0。

结果最多 1000 行；页面/数据集配置限 512 × 1024 字符。新 endpoint 执行器使用共享并发、限速和断路状态，并保存持久加密原始快照；有界过期回退返回 STALE 并保留原抓取时间。新 API 的字段声明同时是服务端响应白名单和类型/脱敏规则；旧 API、SQL、JSON 和 WebSocket 字段声明主要用于绑定、过滤与展示，敏感字段仍应在来源查询中先裁剪。
