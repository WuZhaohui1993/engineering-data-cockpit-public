# 架构总览

本文描述当前工作区实现；运行验收结果见[测试与已知限制](测试与已知限制.md)。

## 定位与范围

工程数据驾驶舱是在 RuoYi 管理系统内实现的配置式大屏模块，用已登记的数据集组织页面、图表、筛选和页面跳转。业务录入、审批、设备采集、业务写回、通用 BI 语义层和独立同步平台不在本模块范围内。

当前功能包括页面文件夹、复制、回收站、设计器、草稿/发布/回滚、页面菜单、登录运行与多页面公开分享；数据集支持 SQL、API、JSON、WebSocket，资源管理支持图片、视频和 GeoJSON。设计器和运行时还包含受控表单、内部嵌入页、富文本和沙箱 HTML；能力限制见[大屏设计器设计](大屏设计器设计.md)和[安全与许可证](安全与许可证.md)。

沿用 RuoYi 登录、角色、菜单、按钮权限、字典和操作日志，不另建账号体系或微服务。页面及数据集尚未实现项目/部门数据隔离，详见[权限与接口设计](权限与接口设计.md)。

## 技术基线与代码入口

| 部分 | 当前基线 | 主要入口 |
| --- | --- | --- |
| 后端 | RuoYi 3.9.2、Java 17、Spring Boot 4.0.3、MyBatis | `ruoyi-backend/pom.xml` |
| 前端 | Vue 3.5.26、Vite 6.4.1、Element Plus 2.13.1、ECharts 5.6.0；JavaScript + Vue SFC | `ruoyi-ui/package.json` |
| HTTP/实时入口 | Spring MVC、Spring WebSocket | `ruoyi-admin/.../web/controller/dashboard/` |
| 业务与执行器 | 页面、版本、资源和四类数据集；第三方 endpoint、媒体和入站接收 | `DashboardService.java`、`DashboardIntegrationService.java` |
| 持久化 | 平台 MySQL；大屏及接入 Mapper | `DashboardMapper.*`、`DashboardIntegrationMapper.*` |
| 页面/API | 页面管理、设计器、数据管理（数据集与接入）、资源、运行态 | `ruoyi-ui/src/views/dashboard/`、`src/api/dashboard*.js` |
| 表与菜单 | 业务表、兼容迁移和菜单权限 | `ruoyi-backend/sql/dashboard.sql`、`dashboard_integration.sql` |

大屏代码直接位于 `ruoyi-admin` 和 `ruoyi-system`，没有独立的 `ruoyi-cockpit` Maven 模块。Redis 沿用 RuoYi 基础设施并保存共享限流、并发与断路状态；数据库保存租约、加密原始快照、审计、告警及入站更新信号。

## 数据与运行链路

```text
管理端 → DashboardController → DashboardService → DashboardMapper → MySQL
                              └→ SQL / HTTP / JSON / 上游 WebSocket
运行端 → 登录权限或分享令牌校验 → 页面版本 → 组件绑定校验 → 数据集执行 → 组件渲染
接入管理 → DashboardIntegrationController → DashboardIntegrationService → IntegrationMapper → MySQL
第三方 → OpenIntegrationController → 接入方认证/幂等台账 → 异步标准化记录
```

- 设计时：配置画布、组件、资源和数据绑定，保存草稿，经服务端校验后发布。
- 运行时：登录入口读取当前发布版本；分享入口读取令牌固定的版本，组件分别取数、刷新和显示异常。
- 页面 JSON 引用 `datasetCode`、字段、参数和资源；数据库及上游接口凭证由服务端使用。
- 平台 WebSocket 周期调用同一执行器。SQL/API/JSON 支持轮询桥接；入站标准记录可由共享版本信号触发更新；原生上游 WebSocket 支持连接复用、心跳和重连。
- 管理外壳跟随 RuoYi 主题与布局大小；大屏内容主题由页面配置决定。时间显示统一复用 `src/utils/dashboard.js`。

## 持久化边界

| 表 | 用途 |
| --- | --- |
| `dashboard_page`、`dashboard_page_folder` | 页面元数据、文件夹、启停、回收站、当前版本指针 |
| `dashboard_page_revision` | 草稿/发布/归档内容、哈希和发布记录 |
| `dashboard_share`、`dashboard_share_page` | 分享令牌、期限、入口和固定版本的页面集合 |
| `dashboard_dataset`、`dashboard_dataset_group` | 数据集声明及树形分组 |
| `dashboard_data_source` | 连接登记、状态和加密凭证 |
| `dashboard_data_source_endpoint` | 一个 HTTP 来源下的受控 endpoint 契约、测试和健康状态 |
| `dashboard_integration`、`dashboard_integration_key`、`dashboard_integration_nonce` | 入站接入方、加密密钥、时间窗与防重放 |
| `dashboard_integration_batch`、`dashboard_integration_message`、`dashboard_integration_record` | 接收批次、逐项状态、异步标准记录和死信 |
| `dashboard_integration_media_ref` | 媒体候选及页面/版本/分享绑定的不透明引用 |
| `dashboard_asset`、`dashboard_map_resource`、`dashboard_resource_folder` | 媒体、GeoJSON 和资源文件夹 |

发布固定页面配置，不固定数据集配置、数据行或资源文件。历史页面和分享仍使用对应编码的数据集现状，详见[页面版本与分享](页面版本与分享.md)。

## 集成与部署

沿用前后端、MySQL、Redis 的单体部署方式，可用 Nginx 提供静态资源及 API/WebSocket/Open API 反代。环境配置和启动步骤见[本地测试指南](本地测试指南.md)。不依赖 JimuReport/JimuBI；早期调研保留的有效选择是页面 JSON、组件白名单、数据源与数据集分层、发布版本隔离。外部 API 主动取数和第三方入站推送的实现及剩余边界见[第三方数据接入需求](第三方数据接入需求.md)；本地已验证多实例租约、恢复消费和跨实例页面更新；生产拓扑与负载须单独验收。

代码保留 `labor` 数据库及 `labor.hik.events` 等环境配置入口；这仅说明适配入口存在，不证明外部项目或现场来源及其字段契约已完成接入。业务来源须按当前环境单独核验，示例 SQL/JSON 不作为现场数据证据。
