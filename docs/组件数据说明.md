# 组件数据与配置说明

设计器选中组件后，点击属性面板中的“数据说明”。该窗口覆盖当前 53 类组件，展示本组件用途、字段角色、标准数据、字段映射和配置要点。通用图表会按当前子类型切换说明，例如散点图显示 X / Y 数值字段。

说明窗口只读。复制数据、映射或配置参考不会修改当前组件，也不会创建数据集或发布页面。

## 用标准样例完成一次绑定

1. 在说明窗口点击“复制数据”，获得 JSON **行数组**，例如 `[{"value":68.5}]`。
2. 多个组件共用时，在数据集管理创建 JSON 数据集，粘贴行数组、解析字段、测试并启用。数值声明为 `number`，日期为 `date`，时间为 `datetime`；不要将 `%` 或单位拼进数值。
3. 在设计器的“数据”页选择该数据集，按说明中的字段表逐项映射，再选择展示字段和顺序。
4. 单个组件的固定内容也可使用“数据来源 → 静态数据”，将相同行数组粘贴到组件中；这份数据只随页面配置保存。
5. 核对组件显示，保存草稿并预览。说明中的“复制字段映射”仅复制 `binding.fieldMap` 对照内容；不要将字段映射或完整页面配置粘贴进数据数组框。

数据集管理负责数据来源、字段与参数。资源管理用于图片、视频、地图等资源。页面 JSON 是布局与组件配置，组件标准 JSON 是数据行，两者用途不同。

## 组件范围

| 分组 | 组件数 | 数据来源 |
| --- | ---: | --- |
| 数据组件 | 13 | 指标、表格、甘特、图文记录等均支持数据集或静态数组 |
| 图表组件 | 16 | 支持数据集或静态数组，按分类 / 数值或专用字段映射 |
| 可视化组件 | 10 | 9 类支持数据；当前时间使用运行设备本地时间 |
| 基础组件 | 14 | 自定义内容可接收绑定数据；其余 13 类使用配置、资源或页面交互 |

合计 39 类显示数据说明，14 类说明配置来源。颜色块和自定义内容也可不绑定数据，直接使用样式配置。查询表单自身无需数据集，它通过页面参数联动目标数据组件；目标数据集须先声明参数。

## 已按运行约定处理的样例

- **普通表格**：提供 8 行，便于在有限可见行数下观察平滑滚动。轮播表格需要把展示条数设得小于总行数。
- **排名表**：原始数据首字段为名称、第二字段为数值；展示列顺序不会改变默认排名依据。
- **甘特图**：提供唯一任务编号、计划 / 实际日期、完成进度、状态和两任务依赖。日期采用 `YYYY-MM-DD`；多个前置任务编号以英文逗号分隔。
- **地图**：标准样例已与 `/dashboard/assets/map/demo-region.json` 的区域名称、坐标对应。先在样式中使用内置示例地图；时间轴飞线有两个分组，能够观察切换。
- **散点图**：两个数值字段映射到 `category → x`、`value → y`，第一点是 `(10, 30)`。
- **日历热力图**：使用有效日期，日历范围应包含 2026 年 9 月。
- **图文记录**：使用脱敏姓名和进出场状态，未附头像时关闭显示头像；准备好平台图片资源后再绑定头像字段。
- **实时列表**：数组只说明事件字段。验证持续订阅须使用已启用的 WEBSOCKET 数据集，静态样例不能代表现场实时接入。
- **自定义内容**：提供可复制的最小静态内容，绑定数据通过 `JLink.onData` 接收，不会因填写字段映射而自动生成界面。
