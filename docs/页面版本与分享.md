# 页面版本与分享

## 页面与版本

页面元数据与版本分开保存：`dashboard_page.status` 为 `0`（启用）或 `1`（停用），`is_deleted` 控制回收站；`dashboard_page_revision.status` 为 `DRAFT/PUBLISHED/ARCHIVED`。页面编码为 3–64 位小写字母、数字、下划线或短横线，是跨页面跳转的稳定标识。

- 新建、复制页面生成独立草稿，不设置运行版本指针。
- 保存只修改草稿内容及 SHA-256 哈希；没有草稿时新建下一版本。当前没有基于旧哈希/版本的乐观锁，多人同时保存可能覆盖。
- 发布在事务中校验草稿、归档原发布版本、将草稿置为 `PUBLISHED` 并更新 `current_revision_id`。后续保存不覆盖该发布内容。
- 回滚只接受本页面的历史发布/归档版本，用历史内容生成新的发布版本；历史 JSON 不改写，但归档操作会更新版本状态及发布相关记录。
- 删除进入回收站；恢复和彻底删除使用独立权限。停用或进入回收站后，运行和对应分享页面不可访问。

服务端保存/发布校验 JSON、组件白名单、画布边界、字段映射、参数/过滤器、交互与资源。画布范围为宽 320–10000、高 240–10000，最多 200 个组件。校验要求绑定的数据集存在；数据集是否启用在实际运行取数时检查，发布成功不代表来源可用。

## 预览与运行

| 入口 | 读取内容 |
| --- | --- |
| 草稿预览 | 优先草稿；没有草稿时回退发布版本，并标记 `previewReadOnly` |
| 历史版本预览 | 指定页面所属版本，只读 |
| 登录运行 `/dashboard/runtime/code/{pageCode}` | 当前发布版本；保留按数字 `pageId` 的旧路由兼容 |
| 分享运行：跟随当前发布 | 已授权页面当前正式发布版本，回滚后跟随回滚结果 |
| 分享运行：固定版本 | 分享固定的页面版本，后续发布不改变该配置 |

预览与正式运行复用数据集执行器，当前没有独立、更严格的预览超时/频率策略。组件分别取数和显示异常。页面配置版本固定，数据集仍按 `datasetCode` 读取当前配置及实时数据，资源也不是版本快照。

页面内“刷新”和当前运行页签的“刷新”会静默核对运行配置；配置、版本及数据集字段定义未变化时，仅更新组件数据，保留画布、排序、输入、选项卡、滚动动画、视频和实时连接。配置实际变化时才重载页面结构；浏览器自身刷新仍会重新加载网页。

页面定时刷新只更新跟随页面周期的数据组件，设置了独立周期的组件按各自周期刷新，静态组件不参与轮询，WebSocket 继续通过原连接推送。相同组件、相同参数的在途请求合并；旧查询与旧页面的迟到结果丢弃。暂时网络故障保留同一查询的上次结果并标记过期状态；权限失效、停用或真实空数据不会继续冒充有效旧结果。

“页面属性 → 数据自动刷新”应保留为默认调度规则，不是整页重载开关。关闭默认刷新时，只有跟随页面周期的组件停止轮询；独立周期及 WebSocket 推送继续运行。预览不自动轮询，仍可手动刷新和接收实时推送。

画布运行滚动条可由 `canvas.hideScrollbar` 控制，隐藏仅影响滚动条视觉显示，不禁用滚动。画布普通适配 `canvas.scaleMode` 支持 `contain`（完整等比）和 `stretch`（拉伸）；全屏适配 `canvas.fullscreenScaleMode` 还支持 `cover`（自适应铺满并可滚动查看超出内容，组件保持比例）。新页面全屏默认 `contain`；历史未设置字段时，普通适配为 `stretch` 则沿用拉伸，否则沿用 `cover`。保存后还需发布，运行页才使用新配置；退出全屏恢复普通适配。

## 分享

`POST /dashboard/page/{pageId}/shares` 创建只读分享，入口页始终加入集合，`pageIds` 可附加其他已发布页面，去重后最多 100 页。`dashboard_share_page` 为每个成员保存 `pageId/revisionId/isEntry/sortOrder`，集合在分享创建后保持不变。

`versionMode` 支持 `FOLLOW_PUBLISHED`（跟随当前发布，新建默认）和 `FIXED`（固定版本）。跟随模式只读取正式发布，不读取草稿，不因新增跳转而自动授权其他页面；回滚后使用回滚产生的当前发布版本。固定模式使用各成员保存的版本号，可以读取已归档版本。固定的是页面布局与组件配置，数据集和资源仍读取当前内容，不是历史业务数据快照；组件内静态数据随页面配置固定。

页面管理的分享列表显示当前模式。具备 `dashboard:share:create` 权限时，可通过 `PUT /dashboard/page/{pageId}/shares/{shareId}` 提交 `{ "versionMode": "FIXED" }` 或 `FOLLOW_PUBLISHED`，保留同一地址、期限及授权页面集合。切为固定时，在事务中把所有已授权页面固定到当时的正式发布版本；任一成员不可用则整次变更失败。同模式重复提交保持幂等，已固定版本不会重新推进。

升级前的分享保持固定版本。其他环境应先执行幂等迁移 `ruoyi-backend/sql/dashboard_share_version_mode.sql`，再部署后端和前端；新增 `version_mode` 列的数据库默认值为 `FIXED`，新建分享由服务端显式采用跟随模式。迁移不更新原有令牌、期限或版本绑定。

有效期默认 24 小时；`expiresUnit` 支持 `HOUR/DAY`，`expiresValue` 范围分别为 1–8760 小时、1–365 天；旧参数 `expiresHours` 仍兼容。`permanent: true` 表示永久，数据库 `expires_at` 为空。

- 入口：`/dashboard/share/{token}`；集合内跳转：`/dashboard/share/{token}/p/{pageCode}`。
- 令牌使用 32 字节随机值，服务端按哈希查找，检查启用/撤销状态及期限。
- 每次页面读取、REST 取数和 WebSocket 推送均检查分享集合、页面状态、按模式解析的版本及组件数据集绑定。固定分享在页面升版后继续读取其归档版本。
- 集合外页面被拒绝；停用/删除页面、撤销令牌、令牌过期或固定版本不可用都会阻止访问。
- 分享列表当前返回可复制的令牌，数据库保留明文 `share_token`；不是“仅展示一次”。取得地址即可访问，没有分享密码或访问次数限制。

分享链接复制兼容普通 HTTP 访问：在点击时先执行与 RuoYi 相同的同步复制，失败时再尝试浏览器 Clipboard API。两种方式均被浏览器限制时，自动选中当前链接输入框并提示按 Ctrl+C（Mac 为 ⌘C）复制。不会要求关闭浏览器安全设置。

已打开的分享页每 30 秒通过 `/public/share/{token}/version`（成员页为 `/public/share/{token}/page/{pageCode}/version`）检查轻量版本信息，不取完整页面配置，也不刷新组件数据。该检查独立于页面“数据自动刷新”；固定模式也检查，以便感知模式切换、过期和撤销。隐藏页面暂停检查，重新可见时立即核对。

版本变化后先读取新配置，再统一更新组件绑定和实时订阅；旧请求、旧连接的迟到结果不会覆盖新版本。更新保留全屏宿主和画布，对仍兼容的页面筛选、表单输入和页内选项卡保留状态。暂时网络失败保留当前画面并重试；分享过期、撤销或页面停用后清除画面。

运行接口只返回页面配置及数据集字段/参数摘要，不返回数据源连接配置。创建者权限没有被固化为项目/部门数据范围，现有分享不能宣称具备行级隔离；凭证与敏感数据边界见[安全与许可证](安全与许可证.md)。

## 页面菜单与跳转

“菜单配置”通过 `POST /dashboard/page/{pageId}/menu` 幂等登记运行菜单，新建菜单默认放入“大屏管理”，不自动分配角色；再次配置保留菜单管理中已调整的父目录、路径、名称、排序、显示状态、权限和业务参数。

手工菜单组件填 `dashboard/runtime/index`，权限填 `dashboard:page:view`，路由名唯一，路由参数填 `{ "dashboardPageCode": "页面编码" }`。页面身份从菜单配置解析，浏览器同名查询参数不能覆盖它；菜单移动后独立编码入口仍稳定。更改菜单后刷新或重新登录加载路由。

部署到菜单的运行页隐藏“返回、版本、刷新、设计”和页面筛选工具栏；页面管理中的“运行”、草稿预览及历史版本预览保留各自的管理工具栏和筛选栏。入口按后台菜单路由标记识别，与菜单目录和路径名称无关；分享及嵌入页面继续隐藏这些管理工具栏。

页面跳转/钻取使用已发布页面选择器和声明参数映射，拒绝外部 URL、协议相对地址、`javascript:` 和反斜杠；分享态页面跳转限定当前集合。独立的 `browser` 点击动作允许校验后的 HTTP/HTTPS 链接，并在新标签打开。内部嵌入页与沙箱 HTML 的限制见[大屏设计器设计](大屏设计器设计.md)。
